# 公开范围与数据说明

本仓库是无旧 Git 历史的源码导出，保留现行网站业务实现。它不是业务备份，也不是旧仓库历史已经清理的声明。

公开内容：应用源码、未改写的 SQL 迁移、通用容器配置、测试，以及合成演示数据。服务 ID 与公开地点名称保留作为代码引用；原始供应商报价、备注、商业长文和照片不发布。

合成金额由 `SHA256("public-demo-v1:" + service_code)` 的前八位生成：基础金额 `101 + int(hash, 16) % 199`，示例旺季增加 37。免费、缺失与需复核的分类用于演示规则，不代表现实价格或优惠政策。原始金额没有参与合成计算；公开测试也移除了生产金额基线。禁止导入线上业务库。

已排除：旧 `.git`、付款记录、真实客户资料、供应商联系人、原始成本表、参考文件、原始摄影、密钥与配置、生产备份、服务器账号/IP、发布归档、求职私聊及历史过程文档。没有给未核实的第三方图片附加许可，而是用新绘制的 SVG 占位插图替代。

发布检查覆盖文件白名单、路径、常见密钥格式、生产标识及引用完整性；自动规则不能证明不存在一切隐私或授予未知版权。源码未另行声明开源许可证，不因仓库公开自动授予额外使用许可。

历史验收仅发布简要范围与结果，不公开客户内容、测试邮箱以外的联系方式、备份名称、云实例标识或会话凭据。默认禁用外部通知，不提供可用于线上运营的账户。
